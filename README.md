# The Bogen Method — Lead Generation Plan

Interactive companion site to the Bogen Method Lead Generation Plan PDF.

**Live site:** https://edmundbogen.github.io/bogen-method-leadgen-plan/

## Features
- Live phase counter (update via `?members=N` URL param)
- Interactive Sellout Math calculator (4-phase MRR/ARR slider)
- Email capture form (Formspree + mailto fallback)
- Downloadable plan PDF
- 16 sections covering strategy, audience, channels, funnel, magnets, content engine, weekly rhythm, 30/60/90, KPIs, tech stack, objections, risk, timeline, and the 7-day launch.

Built for The Edmund Bogen Team · Bogen.ai
